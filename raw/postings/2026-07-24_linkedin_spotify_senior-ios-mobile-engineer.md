## Job Description

Spotify is hiring a Senior Mobile Engineer in Stockholm, Sweden to build next-generation client playback features across iOS and cross-platform mobile targets. You will work on real-time audio processing APIs, reactive mobile UI frameworks, and offline sync engines.

## Key Responsibilities
- Architect native iOS features using Swift, SwiftUI, and Combine/Async-Await.
- Maintain and expand cross-platform mobile components using Flutter and React Native.
- Optimize app launch performance, memory usage, and background audio synchronization.
- Collaborate with backend teams to integrate GraphQL and REST APIs.
- Mentor junior engineers and enforce modular mobile architecture standards.

## Requirements
- 5+ years of mobile software development with primary emphasis on Swift (iOS) and Kotlin/Android or Flutter.
- Deep familiarity with iOS SDK, SwiftUI, XCTest, and App Store distribution pipelines.
- Experience with cross-platform frameworks (Flutter, React Native, Cross-Platform architecture).
- Proficient with CI/CD tools for mobile (Fastlane, Bitrise, GitHub Actions).
