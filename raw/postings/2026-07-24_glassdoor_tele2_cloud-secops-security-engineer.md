## Job Description

Tele2 is looking for a Senior SecOps & Security Engineer in Stockholm, Sweden to secure multi-cloud telecom backbones, manage penetration testing, and ensure ISO27001 and SOC2 compliance.

## Key Responsibilities
- Execute cloud penetration testing, security vulnerability assessments, and OWASP audits.
- Manage IAM access governance, OAuth2 Zero Trust access controls, and AWS GuardDuty.
- Automate Security Operations (SecOps) detection scripts using Python and GitHub Actions.
- Ensure strict ISO27001 and SOC2 compliance across cloud infrastructure.

## Minimum Requirements
- 5+ years in Cyber Security, SecOps, or SOC analysis.
- Experience with AWS, Terraform, Docker, and IAM policy design.
- CISSP or AWS Certified Security certification is preferred.
